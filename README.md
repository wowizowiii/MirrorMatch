# MirrorMatch for Deadly Trick

MirrorMatch is a server-side mod for [Deadly Trick](https://store.steampowered.com/app/3088400/Deadly_Trick/) that forces all players to use the same character.

## How to use

1. Press the `Insert` key to open the mod's menu
2. Enable the mod (only works as lobby host)
3. Select a character or randomize it

As a server-side mod, modifications will only take place if you are hosting the lobby. All players in the lobby will be able to play without having any mods installed.  
Character selection is limited to default characters to preserve financial incentive.
